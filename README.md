# Daily-Habit-Tracker
This Daily Habit Tracker is a simple web application that helps users manage and monitor their daily habits. Users can add habits, mark them as completed, view progress in percentage, and reset the list at the end of the day. It is built using HTML, CSS, and JavaScript with an easy-to-use interface.

## Features
- Add daily habits
- Mark habits as completed
- Auto progress calculation
- Data stored using browser localStorage
- Reset habits at end of day

## Technologies Used
- HTML
- CSS
- JavaScript
- LocalStorage (as database)

## How to Run
Open index.html in any modern web browser.
